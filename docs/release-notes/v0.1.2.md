# rp-macro-writer 0.1.2 – Release Notes

An editable macro text, a resizable window and a better list of your macros.

## What's new
- **Edit the macro text by hand:** the preview is now a real text box. Type into it to fine-tune the generated macro. "Neu erzeugen" returns to the generated text, and the marker line `#rpmw` is added automatically when you save.
- **Syntax highlighting:** commands, `@units`, conditions, `reset=` and comment lines have their own colors.
- **Resizable window:** drag the grip in the bottom-right corner (of the window or of the text box) to make it wider and taller. The window remembers its position and size.
- **Two tabs for your macros:** "Global" lists all account-wide macros, "Dieser Charakter" only those of your current character. Macros made with rp-macro-writer are always listed first.
- **Edit other macros too:** click any macro in the list to load its text into the editor. Macros created by other addons or by hand are changed directly in game when you save them.

## Good to know
- Once you edit the text by hand, changing options no longer changes it. Use "Neu erzeugen" to go back to the generated text.
- Not yet tested in game on WoW Forever or Retail.

## Supported game flavors
WoW Forever, Retail 12.1.x, Mists Classic, Wrath (Titan Reforged), TBC Classic, Classic Era.
