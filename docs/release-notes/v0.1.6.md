# rp-macro-writer 0.1.6 – Release Notes

A rotation for every class, and for every talent tree on WoW Forever.

## What's new
- **"Best rotation" for every class:** one rotation per class and game version, researched from guides and checked against the game's own rotation helper where it is available. Each class has its own file (`Rotations/<Class>.lua`) with the spells, the sources and the reasoning, so you can follow how a rotation came about.
- **WoW Forever: one rotation per talent tree.** All nine Classic classes have a rotation for each of their three talent trees. The addon detects your tree automatically; healer trees without a sensible damage macro use the class default.
- **`/mw rotation`:** prints and saves what the game's rotation helper returns for your character, including the detected talent tree. This is how the rotation tables get checked against the game.
- Death Knight, Monk, Demon Hunter and Evoker are Retail only, because WoW Forever has just the nine Classic classes.

## Good to know
- **Please treat every rotation as a first draft.** All rotation files are marked "unverified": the spell lists come from guides, several rest on a single readable source, and nothing has been checked in game yet.
- The order of the talent trees (1 to 3) is assumed to follow the talent tabs and is not yet confirmed. `/mw rotation` records which tree your character is detected as, so a wrong order can be found and fixed.
- Rank 1 spell IDs are used on WoW Forever; the game resolves higher ranks by name. This is not yet verified in game.
- Macros do not know combo points or procs, so finishers and proc spells are left out on purpose.
- A macro still holds at most 255 characters.

## Supported game flavors
WoW Forever, Retail 12.1.x, Mists Classic, Wrath (Titan Reforged), TBC Classic, Classic Era.
