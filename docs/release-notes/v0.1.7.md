# rp-macro-writer 0.1.7 – Release Notes

Macros longer than 255 characters, and an entry under Options > AddOns.

## What's new
- **Longer macros:** if a macro is still longer than 255 characters after it has been shortened automatically, the text now moves into helper buttons and the macro in game only holds the `/click` lines that call them. Up to 1024 characters in total. The counter turns blue above 255, the saved list marks such macros with a blue `[+length]`, and clicking one loads the full text again. `/mw long` shows the helper buttons and what they hold. Macros made by other addons stay limited to 255 characters.
- **Entry under Options > AddOns:** choose "rp-macro-writer" there and the macro window opens. A button "Fenster öffnen" does the same.

## Good to know
- **Not yet verified in game.** The helper buttons are built like those of the addon Macro Toolkit. Macro Toolkit itself switches its "Extend" feature off on WoW Forever and Retail, because the game seems to limit the text of such buttons to 255 characters. For that reason the text is split into parts of at most 255 characters. If a long macro does nothing when you press it, run `/mw long` and report what it prints.
- A single line longer than 255 characters cannot be split. The `/click` lines themselves must fit into the macro (255 characters).
- Macros are still shortened first (no spaces after commas, `/tar` instead of `/target`); the helper buttons are only used when that is not enough.

## Supported game flavors
WoW Forever, Retail 12.1.x, Mists Classic, Wrath (Titan Reforged), TBC Classic, Classic Era.
