# rp-macro-writer 0.1.8 – Release Notes

Rotation data is collected automatically, one option less, and a list of all commands.

## What's new
- **Rotation dump, automatically:** what the game's own rotation helper returns for your character is now saved silently a few seconds after you log in or reload, when your specialization or talents change, and every time you click "Best rotation". On WoW Forever it is saved per talent tree. Nothing is printed to the chat. The data lets the rotation tables be checked against the game without anybody typing a command; `/mw rotation` still prints it on demand.
- **Commands explained:** the README has a new section "Commands" with every command (`/mw`, `/mw rotation`, `/mw long`), the other ways to open the window (minimap button, Options > AddOns) and the lines the addon puts into its own macros.

## Removed
- The option "Automatisch Gegner wählen" (auto-target enemy) is gone. Saved combinations that had it load without it. Macros you already have in game keep the line until you save them again.

## Good to know
- The rotation tables are still marked "unverified" until the collected data has been compared with them.
- The long-macro helper buttons and the entry under Options > AddOns from 0.1.7 are still waiting for a check in game.
- A macro still holds at most 255 characters; longer text runs through helper buttons (up to 1024 characters).

## Supported game flavors
WoW Forever, Retail 12.1.x, Mists Classic, Wrath (Titan Reforged), TBC Classic, Classic Era.
