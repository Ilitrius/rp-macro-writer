# rp-macro-writer 0.1.1 – Release Notes

Focus and target handling, plus a few safety nets.

## What's new
- **Focus with a fallback:** "Maus-Ziel als Fokus setzen" now sets the focus to the unit under your mouse, or to your current target if there is none (`/focus [@mouseover,…][]`).
- **Target the focus:** the new option "Fokus anvisieren" adds `/target focus`, so your spells simply go to the current target.
- **Target of target as a fallback:** the new option "Ziel des Ziels (Rückfall)" casts on your target if it is a valid enemy, otherwise on its target, otherwise on your target anyway.
- **Name warning:** the preview warns when a spell name contains characters that can break the macro.
- **Items load reliably:** items that are not yet in the client cache are requested and added as soon as their data arrives.
- MIT license.

## Good to know
- Ticking "Maus-Ziel als Fokus setzen" now also ticks "Fokus anvisieren"; untick it if you only want to set the focus. The old behaviour (cast on `@focus`) is still available through the target choice "Fokus".
- The window is a little taller to fit the new options.
- Not yet tested in game on WoW Forever or Retail.

## Supported game flavors
WoW Forever, Retail 12.1.x, Mists Classic, Wrath (Titan Reforged), TBC Classic, Classic Era.
